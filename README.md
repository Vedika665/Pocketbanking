# Pocket Banking

A Java-based desktop banking application that provides basic banking operations with MySQL database integration.

## Features

- User registration and login
- Secure password hashing using SHA-256
- Deposit and withdrawal
- Fund transfer between accounts
- Account balance management
- Transaction history
- MySQL database integration using JDBC
- Database transaction handling with commit and rollback

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- SQL
- OOP

## Project Overview

Pocket Banking is a desktop banking application developed using Java and MySQL. It allows users to create accounts, log in securely, manage their balance, transfer funds, and view transaction history. JDBC is used to connect the Java application with the MySQL database.

## Database

The application uses MySQL to store:

- Account details
- Passwords
- Account balances
- Transaction records

## How to Run

1. Install Java and MySQL.
2. Create the required MySQL database and tables.
3. Add the MySQL Connector/J `.jar` file to the project.
4. Update the database connection details in the Java source code.
5. Run `BankingApp.java`.
